# ADR-269: Calibration gate for semantic grouping

## Status

Accepted

## Context

Similarity clustering can reduce triage noise but can also merge distinct
security findings. A fixed threshold is not enterprise evidence; it must be
measured against reviewed examples and its false-positive tradeoff must remain
visible.

## Decision

The clustering package exposes bounded calibration over human-reviewed pairs.
The report contains confusion-matrix counts, precision, recall, F1 and false-
positive rate. An explicit policy can gate minimum precision/recall and maximum
false-positive rate. The calibration corpus is supplied by the operator and is
not generated by the semantic model.

## Consequences

Organizations can version and review threshold decisions before enabling
semantic grouping. Calibration does not prove corpus representativeness or
model quality on unseen domains; holdout evaluation and independent review
remain required for production claims.
