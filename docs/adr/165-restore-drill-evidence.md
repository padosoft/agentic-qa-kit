# ADR-165: Validate restore-drill evidence against recovery objectives

## Status

Accepted

## Context

The signed backup inventory identifies a recovery set, but production DR
readiness also requires a measured restore. Submitted drill records can drift
from the inventory or omit isolation/integrity checks unless a contract binds
them explicitly.

## Decision

Expose `assertRestoreDrillEvidence` in `@aqa/compliance`. It requires the
source backup and manifest to match the inventory, requires an unchanged
restored manifest, validates UTC start/end ordering, enforces observed RPO/RTO
against the inventory objectives, and requires all four checks: tenant
isolation, audit chain, queue fencing and secret redaction.

## Evidence and boundary

The compliance suite passes 15/15 locally. This validates evidence supplied by
an operator; it does not run Postgres PITR, restore object storage, provision
KMS/Object Lock, or prove the record was generated by a real cluster.
