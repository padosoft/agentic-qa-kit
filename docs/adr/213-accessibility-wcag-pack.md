# ADR-213: Ship an opt-in WCAG accessibility pack

## Status

Accepted — 2026-09-18

## Decision

Ship `pack-accessibility-wcag` with contracts for keyboard operability,
accessible names/roles/states and live-region announcements.

## Boundary

The pack is an automation baseline, not a conformance audit or legal opinion.
Provider/browser/assistive-technology observations and manual review remain
required evidence.
