# Kubernetes pack

This opt-in, provider-neutral baseline checks rendered workload hardening,
admission policy decisions and rollout/disruption resilience for critical
services.

Adapt the placeholder observations to Helm/Kustomize rendering, OPA/Gatekeeper
or Kyverno and a disposable cluster. A passing fixture is not proof of cluster
security, image provenance, network policy, control-plane availability or
production SLOs. Keep apply, chaos and rollback drills separately controlled.
