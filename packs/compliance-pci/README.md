# PCI compliance pack

This opt-in, provider-neutral pack checks three payment-data boundaries: redaction
of PAN/CVV from evidence, tokenization before authorization, and deny-by-default
network segmentation.

The endpoints and fixtures are deliberately placeholders. Adapt them to a
non-production payment sandbox and review secrets, logs, traces, screenshots,
provider scope and retention before execution. A passing run is not PCI-DSS
certification, a QSA assessment, proof of SAQ-D scope, or evidence of live
network segmentation. Never use real PAN, CVV or production payment data.
