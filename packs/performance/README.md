# Performance pack

This opt-in, provider-neutral baseline checks tail-latency SLOs, performance
error-budget attribution/release gating and saturation visibility for critical
journeys such as checkout.

Bind the placeholder observations to k6, Locust, an APM adapter or equivalent
staging evidence. A passing fixture is not a capacity plan or production SLO
guarantee. Use bounded load, synthetic data, explicit test windows and a
reviewed cost/traffic budget; never direct uncontrolled load at production.
