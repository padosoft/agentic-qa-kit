# WCAG accessibility pack

This opt-in, provider-neutral baseline checks keyboard operability, semantic
control exposure and announcements for asynchronous status/errors. Adapt the
placeholder observations to a disposable browser journey, axe-core output or
your accessibility tree adapter.

It is not a WCAG conformance audit, legal accessibility statement, manual screen
reader review or certification. Run it with non-production data and combine it
with manual testing across browsers, assistive technologies, zoom and input
methods.
