# `pack-i18n-l10n`

Opt-in contracts for multilingual and international ecommerce journeys:
locale coverage, translation completeness, money/date/number formatting,
plural rules, approved fallbacks and RTL direction.

## Use it

Tag a project with `i18n`, `l10n`, `localization`, `internationalization` or
`multilingual` and install the pack through the normal `aqa` pack workflow.

## Evidence boundary

The pack is provider-neutral and does not translate content, run visual testing
or certify legal/tax correctness. It cannot prove human translation quality,
font coverage, browser/device layout or regional compliance. Bind contracts to
a disposable storefront and declared locale matrix; provide human linguistic,
visual, tax and legal evidence separately.
